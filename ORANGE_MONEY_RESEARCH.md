# Vérification du paiement Orange Money au Mali

La page officielle Orange Mali « Transfert national » confirme le code direct suivant : `#144*1*NUMERO_DU_BENEFICIAIRE*MONTANT*1*CODE_SECRET#`, puis il faut appuyer sur OK/Envoyer. La même page propose comme alternative de composer `#144#`, de choisir la rubrique « transfert d’argent » et de suivre les instructions.

Pour Prime Service, le numéro bénéficiaire est `94 13 44 08`, sans espaces dans la chaîne USSD. Le montant est injecté par la page de remerciement. Le site affiche `CODE_SECRET` comme placeholder : le client doit le remplacer sur son téléphone et ne doit jamais communiquer ce code au site, au livreur ou au propriétaire.

La page officielle précise que le destinataire doit être un client Orange Mali pour le transfert national standard. Pour un destinataire qui n’a pas encore de compte Orange Money, Orange Mali documente séparément Bèka Transfert avec `#144#11#`; ce parcours ne doit pas être confondu avec le transfert national standard.

La page officielle consultée mentionne également des frais de transfert ; le client doit vérifier le numéro, le montant et les frais affichés avant de confirmer, puis conserver le SMS de confirmation.

Sources officielles : [Transfert national | Orange Mali](https://www.orangemali.com/fr/transfert/transfert-national.html) ; [Bèka Transfert | Orange Mali](https://www.orangemali.com/fr/transfert/beka-transfert.html)
