# Groq Vision — ancien moteur

Prime Service a testé Groq Vision comme remplacement de Gemini, mais les appels de production de contrôle ont renvoyé une requête refusée. Groq n’est donc plus appelé par le formulaire d’inscription.

La fonction `analyser-article-groq` reste conservée dans le dépôt pour ne pas supprimer du code sans nécessité, mais le moteur actif est désormais OpenRouter Free Models Router. Consulter [OPENROUTER_SETUP.md](OPENROUTER_SETUP.md) pour la configuration actuelle.
